# صنعة — نظام إدارة خطوط الإنتاج

سيستم واحد يسجّل كل جنيه داخل وخارج المصنع: من القماش والإبرة لحد التوريد للعميل وتحصيل فلوسه، ومعاه أوامر الإنتاج على خطوطها.

التطبيق ده هو **المرحلة 2** من الخطة: نفس شاشات النسخة الأولى، مع أدوار وصلاحيات، ويتثبت على الموبايل (PWA). بيشتغل دلوقتي بداتا على الجهاز عشان تجرب من غير مفاتيح. لما توصّل Supabase، نفس الشاشات تتربط بالسيرفر.

## التشغيل محلياً

```bash
npm install
npm run dev
```

افتح العنوان اللي هيظهر (الافتراضي `http://127.0.0.1:43127`).

- **اعمل مصنعك**: دفتر فاضي باسم مصنعك.
- **رجّع نسخة احتياطية**: ملف JSON من النسخة الأولى / من زرار التنزيل جوه الإعدادات.
- **دخول تجريبي**: مصنع النور بداتا جاهزة، بثلاث أدوار.

### الأدوار

| الدور | يقدر يعمل إيه |
| --- | --- |
| صاحب المصنع | كل حاجة. هو بس اللي يمسح، أو يرجّع نسخة، أو يضيف موظفين، أو يشوف سجل التعديلات |
| محاسب | يشوف ويسجل ويعدّل الحسابات، ميمسحش |
| مشرف | أوامر الإنتاج والعمال والحضور. مبيشوفش العملاء ولا الخزينة ولا التحصيلات |

من الموبايل: في Safari أو Chrome اختَر **Add to Home Screen** عشان يتثبت باسم صنعة وأيقونتها.

## ربط Supabase (لما تكون جاهز)

1. في إعدادات المشروع على Supabase، في **Exposed schemas**، ضيف `factory`.
2. انسخ `.env.example` إلى `.env` وحط `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY`.
3. في Authentication → Redirect URLs، حط رابط التطبيق بعد ما يترفع.
4. لو مشروع مستقل (مش مشروع الجيم): نفّذ `supabase/schema.sql`.
5. لو المصنع جوه مشروع الجيم الحالي (`ufljewjhajhjcxeyocrk`)، الجداول موجودة في schema اسمها `factory`. جداول الجيم متتلمستش.

من غير الخطوة دي التطبيق يفضل يشتغل بالدفتر المحلي على الجهاز.

## النسخة الاحتياطية

من الإعدادات → **تنزيل نسخة احتياطية**. الملف JSON هو اللي هننقل بيه العملاء والتحصيلات وأوامر الإنتاج والصور للسيرفر.

## إيه اللي موجود في المرحلة دي

- أوامر الإنتاج: ترقيم `SN-####`، خط الإنتاج، نسبة الإنجاز، وحالات مكتمل / قيد التنفيذ / متأخر / متوقف
- العملاء والتحصيل: كشف حساب برصيد متحرك، والآجل، والتحصيل من أقدم توريد
- التحويل البنكي والإنستاباي والمحفظة: صورة إجبارية، ويفضل «مستني تأكيد» لحد ما الفلوس توصل
- زرار واتساب برسالة تذكير جاهزة بالمبلغ
- 18 بند تكلفة، حركات، دفعات، ومورد
- عمال: يومية / شهري / قطعة، حضور جماعي، سلف وخصومات
- خزينة: رصيد كل حساب، أرباح وخسائر لأي فترة، وكل اللي عليك
- موظفين وسجل تعديلات لصاحب المصنع

## اللي بعده (مش في النسخة دي)

المرحلة 3 التنبيهات الأوتوماتيك، بعد ما الداتا تبقى على سيرفر والتطبيق يتثبت على الموبايل. بعدها الإنتاج والمخزن بالتفصيل، المستندات، والتوسع.
