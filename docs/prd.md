# صنعة — SANAA
## Product Requirements Document (PRD)

> **صنعة** مش برنامج حسابات مصنع ملابس. صنعة **نظام تشغيل للتصنيع (Manufacturing Operating System)**
> يخدم أي نشاط إنتاجي قائم على: خامات + عمليات + عمال + مخزون + أوامر إنتاج.
> ملابس، شنط، أحذية، مفروشات، إكسسوارات، جلود، أخشاب، أشغال يدوية، أغذية.

---

## 1. الرؤية

مالك المصنع النهارده بيشتغل على دماغه وكشكول وواتساب. صنعة بتحوّل ده لنظام واحد:
كل جنيه داخل وخارج، كل متر خامة، كل قطعة في الخط، كل عامل، كل عميل، كل ميعاد.

**المبدأ الحاكم:** *Capture once → calculate everywhere.*
المستخدم يسجل الحدث مرة واحدة في مكانه الطبيعي، والنظام يشتق منه:
المخزون، التكلفة، الربحية، رصيد العميل، مستحقات العامل، الخزنة، التنبيه.

**النجم القطبي (North Star):** صاحب المصنع يفتح الموبايل الصبح ويعرف في ٣٠ ثانية:
مصنعي عامل إيه؟ فلوسي فين؟ إيه اللي هيقع النهارده؟

---

## 2. الجمهور والأدوار

| الدور | بيشوف إيه | ممنوع عليه |
|---|---|---|
| **Owner** — صاحب المصنع | كل حاجة | — |
| **Manager** — مدير الإنتاج | الإنتاج، المخزون، العمال، الجودة | الحذف، الاسترجاع، إدارة المستخدمين |
| **Accountant** — محاسب | كل الحسابات: تسجيل، تعديل، تقارير | الحذف نهائيًا |
| **Supervisor** — مشرف خط | عماله + الحضور + أوامر خطه | العملاء، الخزنة، التحصيل |
| **Storekeeper** — أمين مخزن | استلام، صرف، جرد، تحويل | الأسعار والحسابات |
| **Worker** — عامل (بوابة) | شغله، إنتاجه، رصيده | أي حاجة تانية |

قواعد ثابتة:
- **Owner** وحده: الحذف، استرجاع النسخة الاحتياطية، إضافة مستخدمين، سجل التدقيق.
- كل صلاحية تتحقق على **الـ Backend/Database** — مش على الواجهة.

---

## 3. سلسلة القيمة الكاملة

```
Sales → Customer → Sales Order → Product → BOM → Materials → Purchasing →
Warehouse → Production Order → Operations/Routing → Workers → Quality →
Outsourcing → Finished Goods → Delivery → Collection → Accounting →
Cost → Profitability → Analytics
```

كل حلقة فيهم لازم تكون **متصلة بالحلقة اللي قبلها بالبيانات، مش بإعادة الإدخال.**

## 4. الموديولات (Modules)

### M0 — الأساس (مبني ✅)
الهوية، الدخول، الأدوار، العملاء، التوريدات، التحصيل FIFO، بنود التكلفة، العمال،
الخزنة، أوامر الإنتاج (مبسطة)، النسخة الاحتياطية، سجل التدقيق.

### M1 — Product & BOM (المنتجات وقوائم الخامات)
- **Product Master**: كود، اسم، فئة، وحدة، مقاسات/ألوان (Variants)، صورة، سعر بيع، حد أدنى للمخزون.
- **BOM** (شجرة الخامات): لكل منتج/Variant، كمية لكل وحدة، **نسبة هالك (Waste %)**، بدائل للخامة.
- **BOM Versioning**: كل تعديل يعمل نسخة جديدة. أوامر الإنتاج القديمة تفضل مربوطة بنسختها.
- **Routing / Operations**: قص، خياطة، تشطيب، تعبئة… لكل عملية: زمن معياري، سعر القطعة، الخط/المحطة.
- **Cost Rollup**: تكلفة المنتج = خامات (بالهالك) + عمليات + أوفرهيد موزّع.

### M2 — Materials & Inventory (الخامات والمخزون)
- **Materials Master**: كود، وحدة، فئة، مورّد افتراضي، متوسط تكلفة، حد أدنى، نقطة إعادة طلب، مدة التوريد.
- **Inventory Ledger** — *مصدر الحقيقة الوحيد*: كل حركة سطر (شراء، صرف لأمر، مرتجع، تسوية، هالك، استلام تام، تسليم).
  **الرصيد محسوب من الحركات، ولا يُخزَّن أبدًا.**
- **Batches / Rolls / Dye Lots**: تتبع الدفعة من الاستلام للمنتج النهائي.
- **Multi-Warehouse**: مخازن متعددة + تحويل بين المخازن بـ Workflow (طلب → شحن → استلام).
- **Smart Reordering**: أيام تغطية، نقطة إعادة الطلب، مخزون أمان، اقتراح أمر شراء.
- **Valuation**: Weighted Average أو FIFO — اختيار لكل مصنع.

### M3 — Production (الإنتاج)
- **Production Order**: منتج + كمية + BOM Version + Routing + خط + مواعيد.
- **Material Reservation**: حجز الخامات عند الاعتماد، وصرفها فعليًا عند البدء.
- **WIP by Quantity**: كل مرحلة فيها كام قطعة دخلت، خرجت، تالفة، قيد التنفيذ. مش مجرد نسبة.
- **Estimated vs Actual**: تكلفة متوقعة من الـ BOM مقابل تكلفة فعلية من الاستهلاك والأجور.
- **Planning & Capacity**: طاقة الخط باليوم، جدولة، اكتشاف التعارض والاختناق (Bottleneck).
- **Machines & Downtime**: الماكينات، الصيانة، التوقفات وأسبابها.

### M4 — Workforce (العمالة)
- الحضور (يدوي / Excel / بصمة / API)، اليومية والشهري والقطعة.
- **Piece Rate** مربوط بـ (أمر إنتاج + عملية + عامل + كمية سليمة).
- السلف، الخصومات، الحوافز، رصيد كل عامل، تقييم الأداء والإنتاجية.

### M5 — Quality (الجودة)
- فحص بعد كل عملية: سليم / إعادة تشغيل / تالف.
- أنواع العيوب، معدل الجودة من أول مرة (FPY)، تكلفة الهالك، قيمة الخردة.
- ربط العيب بالعامل/الماكينة/الخامة/الدفعة.

### M6 — Purchasing & Suppliers (المشتريات)
- دورة كاملة: طلب شراء → اعتماد → أمر شراء → استلام (GRN) → فاتورة → دفع.
- استلام جزئي، فروق كمية وسعر، رصيد المورّد، **تقييم المورّد** (التزام الميعاد، الجودة، السعر).

### M7 — Sales, Delivery & Collection (البيع والتحصيل)
- أمر بيع → إنتاج → تام → تسليم → تحصيل، بحالة واحدة متصلة.
- التحصيل بطرق الدفع (كاش، بنك، إنستاباي، محفظة، شيك) مع **صورة التحويل إجبارية**
  و**حالة "في انتظار التأكيد"** لحد ما الفلوس توصل.
- التطبيق على أقدم توريد أولًا (**FIFO**)، كشف حساب برصيد متحرك.
- مركز التحصيل: متأخر / النهارده / خلال أسبوع / لاحقًا / منتظر تأكيد + زر **تذكير واتساب** برسالة جاهزة.
- الشيكات: تاريخ الاستحقاق، التحصيل، الارتداد.

### M8 — Finance & Profitability (المالية والربحية)
- الخزنة والحسابات، المصروفات، الأقساط، كل اللي عليك.
- **تكلفة حقيقية**: خامات *مستهلكة* (مش مشتراة) + أجور + أوفرهيد موزّع.
- ربحية: لكل أمر، لكل منتج، لكل عميل، لكل فترة. + حماية الهامش وتنبيه البيع تحت التكلفة.
- التدفق النقدي المتوقع، أرصدة افتتاحية، إصدارات التكلفة (Cost Versioning).

### M9 — Intelligence & Automation (الذكاء والأتمتة)
- محرك التنبيهات + قواعد قابلة للتخصيص + تنبيهات ذكية (اختناق، نفاد خامة، عميل متأخر).
- لوحة القيادة (Command Center)، شاشة صالة الإنتاج، Morning Brief.
- مساعد ذكي **يعتمد فقط على بيانات المصنع — لا يخترع بيانات إطلاقًا**.
- تقارير بلغة طبيعية، تنبؤ بمدى ثقة، تخطيط سيناريوهات.

### M10 — Platform (المنصة)
- Multi-tenant صارم، Multi-branch، بوابات (عميل/مورّد/عامل)، Offline + Sync، Barcode/QR،
  استيراد/تصدير، قوالب صناعات، حقول ومراحل مخصصة، محرك Workflow، خطط SaaS.

## 5. مبادئ المنتج غير القابلة للتفاوض

1. **لا شيء مرتبط بالملابس.** "موديل" → **منتج**. "قماش" → **خامة**. "تفصيلة" → **أمر إنتاج**.
   الملابس مجرد **قالب صناعة (Industry Template)** واحد من عدة قوالب.
2. **الرصيد لا يُخزَّن، يُحسَب** من دفتر الحركات.
3. **لا Delete في المالي والإنتاجي.** بدله: Cancel / Reverse / Void **مع سبب**.
4. **كل حركة مالية Transactional، وكل حركة مخزون Atomic، وكل حركة إنتاج Traceable.**
5. **كل رقم في الشاشة قابل للتفسير** — تدوس عليه يوديك لمصدره (Drill Down).
6. **Mobile-first.** صاحب المصنع بيشتغل من الموبايل وسط الصالة.
7. **لغة بشرية.** "الخامة دي هتخلص خلال ٦ أيام" — مش "Reorder point breached".
8. **مفيش طريق مسدود.** كل شاشة فاضية فيها الخطوة الجاية.

---

## 6. معايير القبول (Quality Bar)

- أي شاشة تفتح في أقل من ثانيتين على موبايل متوسط.
- أي عملية أساسية تتم في **٣ دوسات أو أقل**.
- أي رقم مالي أو مخزوني له **اختبار محسوبات** (Calculation Test).
- أي تعديل حساس مسجّل في **Audit Log** بالقيمة قبل وبعد.
- أي Migration **Backward Compatible** أو معاها خطة ترحيل موثّقة.
