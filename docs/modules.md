# صنعة — الـ٢٢ موديول: فين إحنا فعلًا

الرؤية الأخيرة اقترحت ٢٢ موديول أساسي، وشرط واحد فوقهم كلهم:
**كل موديول مربوط باللي بعده، مش ٢٢ شاشة منفصلين.**

المستند ده مش خطة؛ ده **جرد أمين**. لكل موديول: الحالة، وإيه الموجود بالظبط،
وإيه الناقص وليه.

- ✅ موجود وشغّال على بيانات حقيقية
- ◐ الأساس موجود ومحتاج طبقة فوقه
- ○ محتاج بيانات لسه مش بتتسجّل في النظام

## الشرط الأهم: كل موديول مربوط باللي بعده

السلسلة اللي في الرؤية مش رسم توضيحي؛ دي فعلًا شغّالة في النظام دلوقتي:

```
الجهة → أمر الإنتاج → المنتج → قائمة الخامات → التكلفة → احتياج الخامات
      → الشراء → المخزن → الإنتاج → المراحل → التام → التوريد → التحصيل → الربح
```

وده اللي بيخلي رقم واحد يتغير فينتشر لوحده:

| تغيّر إيه | اتحدّث لوحده فين |
|---|---|
| سعر خامة في حركة شراء | تكلفة قائمة الخامات → تكلفة الموديل → الهامش → سكور الربحية → ترتيب الموديلات → لوحة الربحية → تنبيهات → صحة المصنع |
| تسجيل مرحلة إنتاج | تقدّم الأمر → الباقي في الجدول → مواعيد باقي الأوامر → الاختناق → الجودة → كفاءة الإنتاج → صحة المصنع |
| تحصيل اتأكّد | رصيد العميل → كشف حسابه → سكوره → المتأخر → السيولة → صحة المصنع |
| قرار الطاقة | الجدول كله → مين هيتأخر → الاستثناءات → كفاءة الإنتاج والالتزام بالتسليم |

القاعدة اللي بتضمن ده: **مفيش رقم مشتق بيتخزَّن**. اللي بيتخزّن هو الحركة
(شراء، صرف، مرحلة، توريد، تحصيل) والقرار (سعر، هامش هدف، طاقة، أوزان السكور).
أي رقم تاني بيتحسب وقت العرض — فمفيش «أعد الحساب» ومفيش رقم قديم فاضل معروض غلط.

## اللي واقف على بيانات، مش على كود

أربع حاجات بتفتح لوحدها نص الباقي:

1. **فحص جودة بنوع العيب وسببه** → تحليل الجذور، أكتر عيب، أكتر خط، أكتر عامل، تكلفة الجودة الرديئة.
2. **سجل ماكينات وتوقف بوقته** → OEE، الصيانة الوقائية، تكلفة التوقف، وطاقة لكل مرحلة.
3. **متغيرات المنتج (لون/مقاس) ودفعات** → ربحية اللون والمقاس والدفعة، والتتبع من المورّد للعميل.
4. **باركود وأحداث بدء/إيقاف** → تتبع لحظي، إنتاجية العامل بالزمن الفعلي، والاختناق بالطاقة مش بالرصيد الواقف.

عشان كده الموديولات دي مكتوبة ○ مش «جاية قريب»: مفيش كود يعرف يخترع البيانات دي،
والنظام بيقول ده صريح في لوحة الإدارة تحت «اللي لسه مش مسجّل في النظام».
