# صنعة — الـ٢٢ موديول: فين إحنا فعلًا

الرؤية الأخيرة اقترحت ٢٢ موديول أساسي، وشرط واحد فوقهم كلهم:
**كل موديول مربوط باللي بعده، مش ٢٢ شاشة منفصلين.**

المستند ده مش خطة؛ ده **جرد أمين**. لكل موديول: الحالة، وإيه الموجود بالظبط،
وإيه الناقص وليه. (من ٢٣ لـ٢٨ اتضافوا بعد كده: المصنع كـTenant، وقشرة النظام والتنقّل، والمستندات
والتصدير والطباعة، والمرتجعات والشكاوى، وطبقة الاستنتاجات، والتتبّع والاستدعاء — مش
كانوا في قائمة الـ٢٢ بس من غيرهم المنصة ما تكبرش.)

- ✅ موجود وشغّال على بيانات حقيقية
- ◐ الأساس موجود ومحتاج طبقة فوقه
- ○ محتاج بيانات لسه مش بتتسجّل في النظام

## الشرط الأهم: كل موديول مربوط باللي بعده

السلسلة اللي في الرؤية مش رسم توضيحي؛ دي فعلًا شغّالة في النظام دلوقتي:

```
الجهة → أمر الإنتاج → المنتج → قائمة الخامات → التكلفة → احتياج الخامات
      → الشراء → المخزن → الإنتاج → المراحل → التام → التوريد → التحصيل → الربح
```

وده اللي بيخلي رقم واحد يتغير فينتشر لوحده:

| تغيّر إيه | اتحدّث لوحده فين |
|---|---|
| سعر خامة في حركة شراء | تكلفة قائمة الخامات → تكلفة الموديل → الهامش → سكور الربحية → ترتيب الموديلات → لوحة الربحية → تنبيهات → صحة المصنع |
| تسجيل مرحلة إنتاج | تقدّم الأمر → الباقي في الجدول → مواعيد باقي الأوامر → الاختناق → الجودة → كفاءة الإنتاج → صحة المصنع |
| تحصيل اتأكّد | رصيد العميل → كشف حسابه → سكوره → المتأخر → السيولة → صحة المصنع |
| قرار الطاقة | الجدول كله → مين هيتأخر → الاستثناءات → كفاءة الإنتاج والالتزام بالتسليم |
| صلاحية اتقفلت | القائمة الجانبية → حارس المسار → الأزرار → **رفض الميوتيشن** → سجل التعديلات |
| بيانات التسجيل | نشاط المصنع → الوحدات والفئات والخامات والعمليات · الأقسام المختارة → القائمة الجانبية ودرج الموبايل والبحث و«+ إضافة» · الفريق → قائمة الموظفين · الـslug → تحديد المصنع من العنوان |
| موديل اتضاف من غير قائمة خامات | مساعد التجهيز → بند بأثره في الرئيسية و`/alerts` → وبيختفي لوحده أول ما القائمة تتكتب |

القاعدة اللي بتضمن ده: **مفيش رقم مشتق بيتخزَّن**. اللي بيتخزّن هو الحركة
(شراء، صرف، مرحلة، توريد، تحصيل) والقرار (سعر، هامش هدف، طاقة، أوزان السكور).
أي رقم تاني بيتحسب وقت العرض — فمفيش «أعد الحساب» ومفيش رقم قديم فاضل معروض غلط.

## اللي واقف على بيانات، مش على كود

أربع حاجات بتفتح لوحدها نص الباقي:

1. **فحص جودة بنوع العيب وسببه** (نص الطريق: السبب بيتسجّل على الباندل، لسه ناقص على التسجيل اليدوي) → تحليل الجذور، أكتر عيب، أكتر خط، أكتر عامل، تكلفة الجودة الرديئة.
2. ~~**سجل ماكينات وتوقف بوقته**~~ → **اتبنى في M-M1**: الماكينة ليها كود ودقايق تشغيل، والتوقف بيتسجّل بوقته في تذكرة بتوقّف الماكينة فعلًا، فالجاهزية و MTBF و MTTR وتكلفة الإصلاح بقوا محسوبين. الناقص **تكلفة التوقف نفسها** (محتاجة ربح الدقيقة على الخط) و**طاقة لكل مرحلة**.
3. **متغيرات المنتج (لون/مقاس)** → ربحية اللون والمقاس. ~~**ودفعات**~~ → **اتبنت في M-V1**: الدفعة بقت كيان ليها مورّد ولوط وتكلفة وحالة، والتتبع من المورّد للعميل بقى شغّال في الاتجاهين — سلسلة أمام (الدفعة دي وصلت لمين) وسلسلة خلف (القطعة دي جات من أنهي دفعة).
4. ~~**باركود وأحداث بدء/إيقاف**~~ → **اتبنى في M-S2**: الباندل له كود بيتمسح، والبدء والتوقف والإقفال بيتسجّلوا بوقتهم، فإنتاجية العامل بقت بالزمن الفعلي والاختناق بالشغل الواقف قدام كل عملية. والقراءة بالكاميرا اتعملت في M-Q1؛ الناقص هو البث اللحظي عبر الأجهزة.

عشان كده الموديولات دي مكتوبة ○ مش «جاية قريب»: مفيش كود يعرف يخترع البيانات دي،
والنظام بيقول ده صريح في لوحة الإدارة تحت «اللي لسه مش مسجّل في النظام».
