# صنعة — نظام التصميم (Design System)

المرجع الوحيد للتوكنز هو `src/index.css`. الأرقام هنا وصف لما هو مطبّق فعلًا.

## 1. الألوان

| الاسم | القيمة | الاستخدام |
|---|---|---|
| Navy — كحلي | `#0F1720` | اللون الأساسي، الشريط الجانبي، الأزرار الأساسية |
| Gold — ذهبي | `#D59A3C` | اللون المميز، العنصر النشط، الحالة "قيد التنفيذ" |
| Cream — كريمي | `#F4EFE6` | الخلفية |
| Success | `#2A6B33` | مكتمل |
| Warning | `#8A5A12` | متأخر |
| Danger | `#A3242F` | متوقف / خطر |

لكل لون حالة نسخة `-soft` للخلفيات الخفيفة (الشرائح والتنبيهات).
الذهبي **لمسة**، مش خلفية. لو الشاشة بقت ذهبية يبقى في غلط.

## 2. الخطوط

- **IBM Plex Sans Arabic** — أوزان 400 / 500 / 600.
- العلامة العربية: **صنعة**. العلامة اللاتينية: **S A N A A** بتباعد حروف `0.18em`.
- **Body 16px · Secondary 13px · العناوين بوزن 500 فقط** — ممنوع 700 في أي عنوان.
- الأرقام دائمًا `font-variant-numeric: tabular-nums` (الكلاس `.tabular`) عشان الأعمدة تتظبط.

## 3. الشكل والمسافات

- الزوايا: `sm .375` · `md .625` · `lg .875` · `xl 1.125` · `2xl 1.375rem`.
- الحدود خفيفة `1px` بلون كحلي شفاف — الفصل بالحد مش بالظل.
- الظلال نادرة جدًا: الحوارات والقوائم المنسدلة فقط.
- الاتجاه RTL أصيل: الـ label يمين والقيمة شمال.

## 4. العناصر

| العنصر | القاعدة |
|---|---|
| زر أساسي | كحلي ممتلئ — "حفظ أمر الإنتاج" |
| زر ثانوي | Outline — "إلغاء" |
| زر ذهبي | للإجراء المميز الواحد في الشاشة |
| زر خطر | Ghost أحمر — الحذف ما يكونش صارخ |
| شريحة حالة | `-soft` خلفية + نص بلون الحالة: مكتمل / قيد التنفيذ / متأخر / متوقف |
| كارت | حد خفيف + `rounded-lg`، العنوان يسار الحالة |
| صف بيانات | `DataRow`: اسم الحقل يمين، القيمة شمال، وزن 500 للقيمة |

## 5. أنماط متكررة (Patterns)

- **كارت أمر الإنتاج**: `أمر إنتاج #SN-1042` + شريحة الحالة، صفوف (المنتج / الخط / نسبة الإنجاز /
  ميعاد التسليم / العميل / الربح)، وشريط تقدم بلون الحالة.
- **الكارت الذكي**: كل كارت يجاوب على ٣ أسئلة — ده إيه؟ حالته إيه؟ أعمل إيه دلوقتي؟
- **الحالة الفارغة**: جملة بشرية + زر الخطوة الجاية. ممنوع شاشة فاضية.
- **الجدول على الموبايل**: يتحول كروت، ما يتعملّوش scroll أفقي.
- **التأكيد**: أي إجراء غير قابل للتراجع يطلب تأكيد مكتوب بالسبب.

## 6. اللغة

- عربي مصري بسيط موجّه لصاحب مصنع، مش لمحاسب.
  ✅ "الخامة دي هتخلص خلال ٦ أيام" — ❌ "Reorder point breached".
- ممنوع أي مصطلح مرتبط بالملابس في نصوص النظام الأساسية:
  **منتج** مش موديل، **خامة** مش قماش، **أمر إنتاج** مش تفصيلة.
  المصطلحات دي بتيجي من **قالب الصناعة** اللي المصنع اختاره.

## 7. الهوية البصرية — ما نتجنبه

العلامة مبنية على: الحرفة، الإنتاج، الاتصال، العملية، الدقة.
**بدون** ماكينة خياطة، قميص، أو مبنى مصنع — لأن صنعة مش للملابس.
